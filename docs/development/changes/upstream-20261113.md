# Upstream integration and unit/scenario access

Merged upstream adb868c from the 12 November update. Upstream now owns contribution range filtering, movement, layer controls, walls and experimental surfaces. The old polling/settings bootstrap is removed from the script archive. Remaining local extensions are scheduled once through the simulation pump after scanner initialization.

Later local surface fixes are direct calls: layers expands attached contents; grid passes the explicitly focused surface id into the normal placement acknowledgement; place validates that same focused surface and a native compatible empty slot before the existing ownership, registration and payment transaction. No temporary replacement of the slot helper remains. Chair-hint config reads both native and legacy keys. Custom room names precede inferred names.

Scenario groups now traverse their cards and each card exposes its native Play button separately. Narration uses rendered localized fields and native scenario roles, requirements and goals. Main-menu speech keeps the existing startup transport. Apartment markers use the native PlexLotSelectOverlay identity/eligibility map and existing OnClickImage handler; no pixel guessing or automatic move-in. Rental region/building wrappers expose their existing controls and individual unit cards.

Game inputs remain 1.129.39.1030 and UI Cheats 1.59.1. No new movie is overridden; GameEntryDock gains its native overlay class as one targeted replacement. Full movie and shared-handler gates apply. Live selection, scenario start and placement confirmation remain pending user testing.

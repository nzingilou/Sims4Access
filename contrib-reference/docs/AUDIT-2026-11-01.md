# Contribution source audit

Corrected roof geometry to convert room samples from world coordinates to lot-relative cells using the upstream frame and room-box helpers. Removed calls to the nonexistent Plus frame `tile_of` method.

Corrected the room wall-description wrapper to accept and forward the grid's `objects` argument. Room-name cache now clears when the zone changes.

Removed the repeated chair setting and repeated chair-module import. Failed moves now distinguish successful restoration from failed restoration and log the latter.

Validation: all eleven modules compile under Python 3.7; translated-lot geometry fixture checks room cells and bounds; Git whitespace checks pass.

This branch preserves contribution source for porting. It is not integrated into `Scripts`. Game testing and the upstream build gates remain required when each feature is ported. Ceiling/water anchors, mouse-driven roof/stair construction, and move restoration require game validation; this audit does not certify those paths as working.
